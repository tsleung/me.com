None of the mathematics is ours. What follows is about this drawing of it: what each control changes, the color formula, and the choices that cost something.

Source

Edward N. Lorenz, “Deterministic Nonperiodic Flow.” Journal of the Atmospheric Sciences 20 (1963), 130–141.

James Gleick, Chaos: Making a New Science. Viking, 1987 — opening chapter.

The equations, exactly as implemented 
dx/dt = σ (y − x)
dy/dt = x (ρ − z) − y
dz/dt = x y − β z

σ = 10      ρ = 28      β = 8/3

Integration is fixed-step Runge–Kutta 4 at dt = 0.004, and that step is a constant. The speed control changes how many steps are consumed per frame — never the step size. That is what lets a meta-parameter sweep speed automatically without any risk of quietly changing the shape of the attractor.

The divergence of the field is constant and negative, −(σ + 1 + β) = −13.667: every volume of initial conditions shrinks, forever. Yet nearby points separate exponentially. Volume collapsing while distance explodes is only possible if the set being collapsed onto is stretched and folded without bound — and the butterfly effect is the second half of that sentence.

What each control does
the opening
The page loads black with one button; the pen starts almost still and accelerates over about twenty-six seconds. A line that begins mid-flight at full speed reads as something already in progress. Touch any control and the opening ends.
speed
Simulated time units per real second, 0.08 to 36, geometric. Implemented as steps-per-frame; the integrator never sees it.
trail
How much history stays on screen, 0.4 to 40 simulated time units. A real cutoff, not a decay constant: ink fades exponentially and then is gone, rather than thinning forever into a haze. Measured in simulated time, so the trail means the same length of history at any playback speed.
director: calligraphy
A brush, not a plotter. Curvature is the master signal — you do not take a corner at speed — so a turn presses the brush: slower, thicker, wetter. The moment after a wing change is pressed too, because a stroke does not begin at full speed. Fast lifted runs draw translucent, after a dry brush breaking up. Speed and weight come from one scalar rather than two controls, and that scalar follows its target through a lag, because a loaded brush has inertia and cannot change thickness in one step. The speed slider becomes the tempo. What this does not model is anticipation: a calligrapher slows before the corner because they know the character, and we only know where the trajectory is.
director: tour
One scalar sweeps speed and trail in opposite directions: slow-and-long (the attractor as an object) ↔ fast-and-short (as a process). Both interpolate geometrically, because both are ratio quantities.
director: coupled
Speed is 26/|dX/dt|, so the pen advances at constant arc length and the geometry stops being confounded by the system's own uneven pace. Trail shortens as ‖Δ‖ grows, so memory decays as the forecast does.
ε
How far apart the twin and the reference start. The button sets it to 1.27 × 10⁻⁴, the size of the rounding Lorenz typed in 1961 — though that was a larger twelve-variable model, not these three equations from two years later. The number is the right order of magnitude for an error nobody would think twice about, which is the point of it.
yaw
Rotates x–y before projecting. A setting rather than an animation, because a camera turning under a still attractor competes with the color channel for attention.
σ, ρ, β
Live. Below about ρ = 24.06 the system settles onto a fixed point and stops being interesting, which is worth seeing once.
The color formula

A drawn trajectory has five channels: position, hue, lightness, stroke width, opacity. Every channel coupled to the same variable costs an independent reading — five channels singing the same note is a gorgeous image that says exactly one thing. So each is assigned once: 

position → the state, projected 3D → 2D
hue + L  → ONE selectable scalar field F
width    → the brush, or |dX/dt|
opacity  → age, via the trail fade

f = F(sample) ∈ [0,1]
H = H₀ + arc · f          hue, inside a NARROW arc
C = C₀                    chroma, constant per palette
L = L₀ + (L₁ − L₀) · f    lightness carries the magnitude
α = exp(−age / τ)

The color space is OKLCH, not HSL. Rotating raw HSL hue across a wheel invents structure: yellow is far lighter than blue at the same nominal lightness, so a smooth scalar picks up bright bands that look like features of the attractor and are artifacts of the color space. OKLCH is designed to be perceptually uniform, so equal steps in L look roughly equal. Narrow hue arc, magnitude on L — hue for identity, lightness for amount. The spectrum palette breaks that rule on purpose, and seeing its banding next to a well-behaved ramp teaches the rule better than the rule does.

What the numbers mean
λ measured
The largest Lyapunov exponent, computed live: walk a reference and a shadow, record how much the gap grows, then pull the shadow back to its original distance and keep going. The renormalization is the trick — without it the gap saturates at attractor diameter and the slope collapses toward zero. For 10, 28, 8/3 it lands near 0.905. The app measures this rather than quoting it.
λ this fork
The same quantity fitted to the run on screen. Noisier, and it should agree; when it badly disagrees you are looking at a fork that got unlucky about where on the attractor it started.
horizon, predicted / measured
Predicted is (1/λ)·ln(tol/ε). Measured is when ‖Δ‖ actually passed the tolerance on this run. Both are how long the twin stays a usable prediction of the reference.
per 10× better ε
ln(10)/λ ≈ 2.54 time units — the number worth carrying out of here. Improving your initial measurement tenfold does not double your forecast; it adds a fixed constant. Another tenfold adds the same constant again. The return on precision is logarithmic, and the exponent sets the exchange rate.
Choices that cost something
The trail is kept and redrawn every frame.
The cheap way is to never clear the canvas and age the ink by pulling alpha out of the whole surface once a frame. But that can produce exactly one curve — every pixel gets the same treatment every frame, so old ink can never fade faster than new ink, and the tail thins forever instead of ending. Keeping the vertices buys an arbitrary fade curve and a real cutoff. Cost: draw calls, paid down by quantizing pen state into runs, which works because color and weight vary smoothly along a trajectory.
Both trajectories wear the same colors.
Tinting the twin would make it easy to follow and would undercut the whole demonstration — the point is that for a while you cannot tell which is which. Once they separate the twin draws thinner and fainter, so it reads as the reference's shadow rather than as a second equal line, and the heads differ throughout: filled dot for the reference, ring for the twin.
ε defaults to the rounding, not to machine epsilon.
A tinier ε makes a longer, more dramatic run. The honest default is the size of error a person actually makes.
Re-fork on saturation is on.
Once ‖Δ‖ passes 25 the twin is simply elsewhere and there is nothing left to watch. Turn it off to run a single pair forever.
